# Nebula Dashboard - Fresh Design (Vite + React + Tailwind + Framer Motion)

This project is a fresh, original dashboard inspired by various DeFi apps but redesigned with a unique UI and color palette.

## Setup

1. Install dependencies:
```bash
cd nebula-dashboard
npm install
```

2. Run the dev server:
```bash
npm run dev
```

3. Open http://localhost:5173 in your browser.

## Notes

- Wallet connect uses `window.ethereum` (MetaMask). If you want WalletConnect or RainbowKit I can add that.
- Routes: `/` (Dashboard), `/referrals`, `/stats`.
- Design: dark navy background, neon gradient accents, glassy cards, Orbitron headings.
